# LENTICULAR CARD STUDIO

v1.0 · [在线使用](https://demi-tequila.github.io/lenticular-card-studio/) · [English README](README.md)

整个工具就是 `index.html` 一个文件。双击打开，拖一张照片进去，导出 PNG。不用装依赖、不用注册、不上传照片，图片只在浏览器里用 Canvas 处理。

界面默认英文，右上角可切中文；`?lang=zh` 直接进中文版。英文文档是主文档，这份是中文速记，内容不逐句对照。

## 跑起来

直接双击 `index.html` 即可。如果浏览器限制本地文件的剪贴板权限，起个静态服务：

    python3 -m http.server 8000

`?demo=1` 会加载程序生成的示例图，不用先找照片就能看到六层材质的效果。

## 六层画的是什么

卡片画布 420 × 600：照片裁切填满 → A/B 交错条带（鼠标位置或手机倾斜决定混合比例）→ 每条柱镜内部的明暗渐变 → 七色镭射渐变 → 镜面高光、上下压暗、细金边 → 卡面文字。

「导出打印光栅片」只保留固定 50/50 交错和柱镜渐变，去掉镭射、金边和文字。那是给印刷用的片子，不是预览图。

## 参数

| 参数 | 范围 | 默认 | 作用 |
| --- | --- | --- | --- |
| 光栅密度 LPI | 12–100 | 40 | 404 px 图像区里的柱镜条数。越高越细，实物对位越难。 |
| 翻转角度 | 0–45° | 18° | 视角变化多快会从 A 面切到 B 面。 |
| 视差深度 | 0–1 | 0.40 | B 面由 A 面派生时的裁切位移量与色彩偏移量。 |
| 镭射强度 | 0–1 | 0.85 | 虹彩强度，双图光栅模式下不画。 |
| 柱镜强度 | 0–1 | 0.22 | 每条柱镜内部明暗对比。 |

三个生成模式只是同一套滑块的预设，不是三套渲染器。对应的 JSON 在 `presets/`。

## 分享与预设

「复制分享链接」把整份状态写进 URL 的 `#` 后面，包括语言、模式、五个参数、导出倍率和三行卡面文字。对方点开链接后自己拖照片。

照片不进链接，是故意的：转成 data URL 会让链接变成几 MB，也等于把别人的照片贴进聊天窗口。「导出预设 (.json) / 导入预设」是同一份状态的另一种形式，贴到 issue 或讨论区更方便。

## 打印

物理柱镜片的节距要和导出的 LPI 对得上。40 LPI 大致对应 0.635 mm 节距的柱镜片。打印片是 840 × 1200 px、2× 输出，尺寸按你要印的实物大小来定。对位余量很小，先印一条窄条试，别一上来就整版。屏幕预览不能当打样。

## 已知问题

- B 面是 A 面移位加调色的副本，视差是错觉不是几何。想要真的双图翻转，请导入第二张照片。
- iOS 上 `deviceorientation` 需要用户手势授权，点一下 A/B 横条；没授权时桌面端鼠标倾斜照常可用。
- B 面用到 Canvas `filter`，老浏览器不支持时只有裁切位移，没有色彩偏移。
- 100 LPI + 3× 导出在手机上会比较慢。
- 明暗主题只换界面，不换卡面。

## 社区怎么参与

讨论区放作品和预设：发导出 PNG 时顺手贴上分享链接，或直接贴 `.json`。如果你真印过，写下用的 LPI、柱镜片和打印机型号，这比多一张截图有用。渲染出 bug 请提 issue，附浏览器版本和「复制分享链接」得到的链接，通常靠这条链接就能复现状态。

加一个预设只需往 `presets/` 放一个文件并发 PR，不用改代码。细节见 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 出处与许可

参数命名（pitch / stripe / flipAngle / depth / foil）参考 [EverettFish/holo-card-studio](https://github.com/EverettFish/holo-card-studio) 与 [Cafe-lentique](https://github.com/Cafe-lentique) 的 `interlacer.py`，交错算法还看了 [fopina/lenticular.py](https://github.com/fopina/lenticular.py)。这里没有引入它们的任何代码，只是把参数模型搬到纯 Canvas 上，并改成一张照片就能出图。
